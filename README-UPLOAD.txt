SUMMER → SEPTEMBER — ЗАГРУЗКА НА GITHUB PAGES

1. Откройте свой репозиторий на GitHub.
2. Удалите старые файлы сайта из корня репозитория или загрузите новые с заменой.
3. Распакуйте готовый архив.
4. Загрузите В САМ КОРЕНЬ репозитория всё его содержимое:
   index.html, 404.html, папку assets и остальные файлы.
   Не создавайте дополнительную внешнюю папку для этих файлов.
5. Нажмите Commit changes и выберите Commit directly to the main branch.
6. Откройте Settings → Pages.
7. В разделе Build and deployment выберите Deploy from a branch.
8. Branch: main, Folder: / (root), затем Save.
9. Подождите 2–5 минут и откройте ссылку GitHub Pages.

Если после обновления видна старая версия, обновите страницу сочетанием
Ctrl + F5 или откройте сайт в приватном окне браузера.

Перед новым учеником нажмите кнопку New student в верхней части сайта и
подтвердите полный сброс. Ответы хранятся только в браузере этого устройства.

YouTube может быть недоступен в отдельных сетях. В каждом видеоблоке есть
локальная кнопка Video not playing? Use the audio version.
